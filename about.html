About the Project

This project visualises data from the IUCN Red List API v4 across three interactive 3D globes. The Species Map plots 200 threatened species (Critically Endangered, Endangered, and Vulnerable) with live data fetched on demand. The Conservation Score globe ranks countries by their conservation effort. The Forest Cover globe displays global tree-canopy data. A unified dashboard provides summary statistics across all three views.
